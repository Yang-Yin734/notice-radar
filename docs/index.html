应用要改的是仓库变量，所以需要一个能改 Variables 的令牌：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 只授权本仓库，权限勾 Variables: Read and write。

安装到手机

⬇ 下载 Android 安装包（APK）

Android：下载后按提示安装（首次需允许「安装未知来源应用」）。安装包里已包含界面与当前数据， 打开不需要联网、也不会跳浏览器；联网时会自动尝试镜像刷新最新通知。

iPhone / iPad：用 Safari 打开本页 → 点底部 分享 → 添加到主屏幕。iOS 不允许像 Android 那样直接装安装包（必须有 Apple 开发者账号签名）， 「添加到主屏幕」就是苹果官方给网页应用的安装方式：同样有独立图标、全屏显示、可离线。

关于

它把学校官网的通知自动抓下来、按关键词过滤、归档成可检索的列表 —— 只抓公开页面，不登录、不存储个人信息。

数据由 notice-radar 定时抓取并提交到仓库。站点结构变更可能导致漏抓，请以学校官网原文为准。
