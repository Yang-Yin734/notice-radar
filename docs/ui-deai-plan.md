## 0. 先说视频内容（结论：它讲的正是"为什么一眼 AI"）

这条视频不是 App 录屏，是一条设计教程。用 ffmpeg 抽 121 帧 + Windows OCR 逐帧识别后，内容如下：

**0–20s｜反面教材**
一个创作者工具 App「创作台 CREATOR STUDIO」：总览 / 内容日历 / 选题灵感 / 数据分析 / 待办清单 五个 tab，上来就是 6 宫格数字（4.3万 / 22.4万 / 45 / 3…）+ 满屏圆角白卡片 + 灰色小字说明。字幕：「就是 ai 生成的」。

**20–99s｜5 个参考站**
| # | 站点 | 干什么用 |
|---|---|---|
| 1 | motionsites.ai | 首屏/Hero 与 3D 站点库，可 Copy full prompt / Copy source code |
| 2 | mobbin | 真实品牌 App 的 Screens / Flows / UI Elements（当场看了 CRED onboarding、Duolingo onboarding） |
| 3 | reactbits.dev | 动效 React 组件（Gradient Waves 等 217 个组件与背景） |
| 4 | shadcnblocks.com | 成套区块：230 Components / 300 Blocks / 15 Templates |
| 5 | uiverse.io | 开源 UI 小元素（按钮、复选框、开关、卡片、加载器），每个都有 Get code |

**99–121s｜技巧与结论**
「我最常用的技巧就是截图复刻」→ 截图丢进对话框 → 提示词是：
> 「**不改变我现有代码的功能，帮我复刻这个界面的风格**」

结尾两句是整条视频的答案：
> 「AI 就是个特别勤快的复印机」
> 「它自己没有审美，所以 AI 不行，只是因为没给对参考文件」

**所以要照抄的不是它的配色，是它的方法：先钉约束（设计令牌），再给对参考物（截图复刻），最后只允许在约束内复刻。**

顺带一个对照：视频里那个"一眼 AI"的反面样本（4 tab + 6 宫格数字 + 圆角卡片堆叠 + 满屏灰色小字），和校园通知雷达现在的信息架构**几乎同构**。这不是巧合——同一个套路。

## 2. 设计定位（先定方向，再定像素）

去 AI 味不是"少用蓝色"，是**先决定这套界面像什么实体东西**。

### 主推 A：公告栏 / 教务处的纸
- 语义对：校园通知 = 公告 = 纸质公告栏 + 红头文件
- 配色有出处：暖白纸 + 墨黑字 + 朱红印章色
- 层级天然：纸上是"标题压正文"，不是"卡片叠卡片"
- 深色模式好办：暖黑而不是蓝黑

### 备选 B：档案馆 / 档案卡片
米黄 `#F4EFE3` + 深棕 `#3B2F26` + 铁锈色，更旧、更沉，适合"存档/归档"叙事（统计页叫"归档"）。

### 备选 C：克制的工具
近白 `#F7F7F8` + 石墨 `#18181B` + 单色强调（但**必须换掉 #1C7ED6**）。最安全、差异最小、也最像"设计过的工具"而不是"AI 生成的工具"。

> 建议走 A。B 太旧会牺牲可读性；C 与现状差距太小，改了等于没改。

## 3. 设计令牌（可直接落成代码）

新建 `android/app/src/main/java/io/github/yangyin734/noticeradar/ui/Tokens.kt`，全应用只从这里取色/字/距/角。

### 3.1 颜色

**浅色**
| 令牌 | 值 | 用途 |
|---|---|---|
| `paper` | `#FBFAF7` | 页面底 |
| `surface` | `#FFFFFF` | 卡片/输入框 |
| `ink` | `#1A1A1A` | 标题、正文主色 |
| `ink2` | `#3F3F3F` | 正文次要 |
| `muted` | `#6E6A63` | 说明、时间、计数（对比度 5.2:1） |
| `line` | `#E7E2D8` | 0.5dp 描边、分隔线 |
| `accent` | `#B23A2E` | 朱红：未读、选中、主按钮（仅此一处强调） |
| `accentSoft` | `#F6E7E3` | 强调浅底 |
| 考务 | `#A63D2F` | tag |
| 教学 | `#2F5D7C` | tag |
| 学生事务 | `#3F6B4A` | tag |
| 讲座学术 | `#5E5680` | tag |
| 其他 | `#6E6A63` | tag |

**深色**：`paper #151311` / `surface #1D1A17` / `ink #EDE9E2` / `ink2 #C9C4BA` / `muted #9A948A` / `line #2C2822` / `accent #D9614F` / `accentSoft #33231F`；5 个 tag 色各提亮约 15%（见实装）。

规则：**全应用只有 1 个强调色**；语义色只出现在标签的**文字与描边**上，不铺底色（饱和度全部压到 ≤55%）。

### 3.2 字阶（5 级，砍掉其余 10 个半档）

| 级别 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `Display` | 28 / 34 | SemiBold | 页面大数字、统计首位 |
| `Title` | 17 / 24 | SemiBold | 页面标题、通知标题 |
| `Body` | 15 / 22 | Regular | 通知正文、设置行 |
| `Label` | 13 / 20 | Medium | 按钮、tab、行标题 |
| `Micro` | 11 / 16 | Regular | 计数、时间、tag（**全应用最小，不再往下**） |

数字统一 `FontFeatureSetting("tnum")`（等宽数字），便于纵向对齐比较。

中文行高不低于 1.45×（15sp → 22sp 已满足）。

### 3.3 间距

`4 / 8 / 12 / 16 / 20 / 24 / 32`，只用这 7 个值。
页面左右 `16`，列表项内 `14`，卡片间距 `10`，分组之间 `24`。

### 3.4 圆角（3 个值）

| 令牌 | 值 | 用途 |
|---|---|---|
| `ShapeCard` | 10dp | 卡片、输入框 |
| `ShapeControl` | 8dp | 按钮、chip、图标按钮 |
| `ShapeTag` | 3dp | 标签 |

取消 14 / 20 混用；药丸形（999）只允许用在"未读数"一个地方，或干脆不用。

### 3.5 阴影 → 描边

所有卡片 `elevation = 0.dp` + `border = 0.5dp line`。网页版 `box-shadow` 全删，改 `border:1px solid var(--line)`。

唯一例外：底部导航栏保留 1 条上边线，不用阴影。

### 3.6 图标（去 emoji 的实装路径）

现状依赖里**没有** `material-icons`，所以直接用了 emoji。两条路，推荐第一条：

**A. 自绘 VectorDrawable（推荐）**
新建 `res/drawable/`：
- `ic_notice.xml`（告示/喇叭，24dp，stroke 1.6）
- `ic_star.xml` / `ic_star_outline.xml`
- `ic_chart.xml`
- `ic_settings.xml`（齿轮，极简 8 齿）
- `ic_refresh.xml`、`ic_moon.xml`、`ic_sun.xml`、`ic_close.xml`、`ic_chevron.xml`、`ic_search.xml`、`ic_check.xml`

用 `painterResource(R.drawable.ic_notice)` + `Icon(tint = …)`。体积 < 8KB，不加依赖，风格统一（同一套 1.6px stroke）。

**B. 加 `material-icons-extended`**：一行依赖搞定，但包体多 ~2MB（R8 会裁，未开混淆时全打包），且是"Google 默认图标"，仍是通用味。**不建议**。

### 3.7 动效（克制，只 4 处）

1. 列表项按下：`scale 0.985` + `150ms`
2. tab 切换：下划线 `animateDpAsState` 滑动，`220ms` ease-out
3. 未读色条：进入时宽度 `0 → 2dp`，`180ms`
4. 已读切换：整卡 `alpha 1 → 0.86`，`160ms`

不引入任何第三方动效库（视频里的 reactbits 只借"微交互"这个思路，不借实现）。

## 4. 逐页改造

### 4.1 通知流（收益最高，先做）

**顶栏（AppHeader L507-532）**
- 现状：`标题 + 「N 条 · 未读 M」 + ☀ + 刷新` 全挤一行，右侧两个 TextButton 抢重心
- 改：两行结构
  - 第一行：`校园通知雷达`（Title 17，墨黑）｜右侧：学校名（Micro，muted）+ 刷新图标按钮
  - 第二行：`未读 4 · 共 128 条`（Micro，muted，未读数字用 accent 色）
- 主题切换从顶栏移除 → 收进设置页（那是低频操作，占着首屏是浪费）

**搜索（L574-580）**
- 去掉 `OutlinedTextField` 的描边方框 → 改成 `paper` 底 + 8dp 圆角 + 左侧搜索图标 + 占位「搜标题：退课 / 四六级 / 推免」
- 高度 40dp，不做全屏宽边距 16

**来源筛选（L582-595）**
- 药丸 chip → **横向下划线 tab**：文字（Label 13）+ 选中项 accent 下划线 2dp + 计数为 Micro 上标
- 理由：通知来源是"频道"，不是"标签"，下划线 tab 更接近内容产品的心智，也顺手干掉"黑药丸"

**日期分组（L620-635）**
- 现状：日期 + `N 条` 药丸，横向一行
- 改：**左侧时间轴**
  - 左栏宽 46dp：日期拆两行（`10/27` / `周一`），Micro 灰
  - 右栏：细竖线 1dp `line` 色，从分组头贯穿到组内最后一项
  - 效果：整屏读起来像"时间轴上的通知"，一眼是"信息流"，不是"卡片墙"

**通知卡（NoticeCard L669-728）——重点重构**
```
┌──────────────────────────────────────┐
│▎ 教务处 · 9分钟前              ☆     │   ← 来源 Micro muted ｜ 收藏图标右上
│  2026年秋季学期退课办理的通知          │   ← Title 17/24，最多 3 行
│  [考务]  10-27 截止                    │   ← tag 描边 + 截止 Micro
└──────────────────────────────────────┘
```
- 色条：`Modifier.fillMaxHeight()` + 父 Row `height(IntrinsicSize.Min)`，**修掉 56dp 写死**
- tag：`border 1px tagColor, color tagColor, padding h6 v1, radius 3` —— 去掉彩色实底
- 收藏：`ic_star_outline` 16dp，选中填 `accent`
- 已读：标题色 `ink → muted`，卡整体 alpha 0.86
- 卡片：白底 + 0.5dp 描边 + 圆角 10，无阴影

**空态（L597-612）**
- 一句话 + 一个按钮：「还没勾选学院」+ `[去勾选]`（直接跳设置页并展开选校卡）

### 4.2 收藏

- 与通知流共用列表，但顶部加一行 `按来源分组` 的横向 tab，空态文案「收藏夹是空的 · 在通知上点 ☆」

### 4.3 统计（把"6 宫格 + 4 图"砍成"1 主 3 副"）

新结构，从上到下：
1. **大数字区**（一行三格，无卡片底）：`128` 累计 / `24` 近 7 天 / `7` 有新增天数 —— 数字 Display 28，标签 Micro
2. **主图：近 14 天发现量** —— 细柱（2dp 宽间隙）+ 峰值柱用 `accent`，其余 `ink` 20% 透明度；去掉渐变与圆角柱头

5. 星期分布并入主图，用「7 天 / 14 天」分段控件切换（不再单独占一张卡）

- 组标题：`你在看哪所学校` / `数据` / `关于`（Micro + 全大写间距，组间 24dp）

- 「关于」：`v0.11.2` + `项目主页 ›` 两行，删掉那两段免责长文（移到 README / 首次安装提示里）
- 更新横幅（L372-401）：蓝底块 → 顶部细条：`│ 发现新版本 0.12.0   更新 ›`（左 2dp accent 竖线 + 白底 + 下边线），点整条进更新流程

### 4.5 选校 / 选学院

## 5. 去 AI 味 10 条硬规则（写进 CONTRIBUTING，作为 review 检查项）

1. 全应用只有 **1 个强调色**；语义色 ≤ 4 个，饱和度 ≤ 55%，只用于文字/描边
2. **UI 里不允许出现 emoji**（用户内容除外）
3. 字号只能取 5 级字阶，出现 10.5 / 11.5 / 12.5 / 13.5 / 14.5 一律打回
4. 圆角只有 3 个值
5. 卡片一律 0.5dp 描边 + `elevation 0`，不允许阴影
6. 不允许渐变（唯一例外：主图峰值柱）
7. 中文行高 ≥ 1.45× 字号
8. 说明文案 ≤ 12 字；同一条说明在应用内只出现一次
9. 每屏只有 1 个主按钮（实底），其余为文字按钮
10. 数字一律 tabular，右对齐可比
